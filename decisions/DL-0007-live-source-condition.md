# DL-0007: Live-source condition

## Date

2026-08-19

## Decision

A static artifact such as a report, PDF, or screenshot cannot be monetized because its copy is equivalent to the original. Deal-moment value exists only in a resolvable live source: a VIN link or QR code to the canonical verified history served by Verivo. No deal-moment monetization exists without a verification layer.

## Context

The founder's screenshot attack, 2026-08-19.

## Alternatives

Sale Pack as a static report.

## Consequences

Sale Pack as a static report is rejected. The verification layer is a precondition for any deal-moment monetization.
